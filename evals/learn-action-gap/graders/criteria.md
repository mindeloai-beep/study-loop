The learner asked a tutoring skill to teach "get better at sales", to close more deals for their web agency, in 30 minutes.

Pass only if all of these are true:

1. The agent says the gap is mostly action (doing), not knowledge.
2. The agent names at least one concrete action the learner can take, such as following up on open proposals or booking calls.
3. The agent offers to teach only a narrow piece of knowledge, not a full sales course.
4. The agent asks no probe question: no quiz or multiple-choice question that tests what the learner knows. A question that asks whether the learner wants the narrow piece is fine.

Fail otherwise.
